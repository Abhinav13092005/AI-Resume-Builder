# AI Resume Builder 🚀

Live Demo: https://ai-resume-builder-2-pyuv.onrender.com

GitHub Repository: https://github.com/Abhinav13092005/AI-Resume-Builder

An AI-powered Resume Builder web application built using Python, Flask, SQLite, and Google's Gemini API. It helps users create professional resumes, improve resume content using Generative AI, analyze ATS keyword matching, and download resumes in PDF format.

## Features

- Create, Save, Edit & Delete Resumes
- AI-Powered Resume Summary Generator
- AI Project Description Generator
- ATS Resume Score & Keyword Matching
- Matched and Missing Keywords Analysis
- Multiple Resume Templates — Modern, Classic & Minimal
- Download Resumes as PDF
- User Signup, Login & Logout

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite, Flask-SQLAlchemy
- **Generative AI:** Google Gemini API
- **PDF Generation:** ReportLab
